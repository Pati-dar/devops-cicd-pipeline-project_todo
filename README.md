# 🚀 DevOps CI/CD Pipeline Project

## Overview
This project demonstrates an end-to-end CI/CD pipeline using Jenkins, Docker, and Kubernetes.

## Tech Stack
- AWS (EC2 / EKS)
- Jenkins
- Docker
- Kubernetes
- GitHub

## Workflow
1. Code pushed to GitHub
2. Jenkins pipeline triggered automatically
3. Docker image built and pushed
4. Application deployed on Kubernetes

## Setup Steps
- Launch EC2 instance
- Install Jenkins, Docker, kubectl
- Configure Jenkins pipeline
- Connect GitHub webhook

## Outcome
- Automated deployments
- Reduced manual effort
- Scalable architecture
